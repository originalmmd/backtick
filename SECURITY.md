# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Backtick, please report it
privately by emailing **originalmmd@gmail.com**.

Please do **not** file a public GitHub issue for security vulnerabilities.

You should receive a response within 48 hours. If you do not, please follow
up to ensure the message was received.

We appreciate your help in keeping Backtick secure for everyone.
